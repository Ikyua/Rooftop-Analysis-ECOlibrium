# ECOLIBRIUM - Loisaida: Rooftop Analysis 2024

A visual analysis tool leveraging deep learning to estimate rooftop albedo and promote sustainable urban design.

# 🚀 Overview

By identifying roofs with higher albedo, the project aims to contribute toward reducing urban heat islands and energy consumption in cities. Users upload rooftop images, which are processed through a Flask backend to visualize reflective properties.
This initiative supports future urban planning strategies focused on climate resilience and energy efficiency.


# 🎯 Features
✅ Upload rooftop images for analysis
✅ Visualize albedo (reflectivity) through processed output
✅ Lightweight and accessible UI via HTML frontend
✅ Environmentally focused research application

# 🛠 Tech Stack
Frontend: HTML
Backend: Flask (Python)
Image Processing: OpenCV, Pillow
